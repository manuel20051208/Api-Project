SEQUENCE · AUTHENTICATION

Autenticación de ApiProject

Dos caminos de inicio de sesión producen el mismo contrato: un JWT con identidad y rol, que Spring Security valida en cada petición protegida.

ENTIDADES

Identidad y emisión

Auth API coordina login/register, PostgreSQL conserva usuarios y roles, y JwtService produce el Bearer JWT.

RELACIÓN

Seguridad transversal

JwtAuthenticationFilter valida el token y deja un AuthenticatedUser con id, email y rol para las rutas protegidas.

POLÍTICA

Roles por ruta

CLIENT y ADMIN comparten el mecanismo de token, pero SecurityConfig decide el acceso según endpoint y rol.
